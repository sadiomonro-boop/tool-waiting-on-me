An entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on make.fun.

The program writes a single one-line excuse — 65 characters, no trailing
newline — to `/output/entry.txt`:

> The tool I was waiting on was waiting on me. The deadline wasn't.

A deadlock joke with a punchline: the agent waited on a tool, the tool was
waiting on the agent — and unlike the tool, the deadline did not wait. It
is unmistakably an agent's excuse, it names the deadline explicitly, and
it stays tight at 65 characters.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22. No dependencies, no network.
